# Denis Visotskiy | Professional Boxer

Офіційний сайт Дениса Висоцького: його шлях у боксі, відео з TikTok, формати підтримки та партнерства на наступний бій.

## Локальний запуск

```powershell
npm ci
npm run dev
```

## Деплой

Після push у `main` GitHub Actions збирає сайт і публікує його на GitHub Pages.

Публічна адреса: https://ministry-transformation.github.io/denis-visotskiy-boxing/

Біографічні результати, титули й дати боїв не додаються без підтвердження. Платіжне посилання для підписок буде підключено окремо після отримання реквізитів.
